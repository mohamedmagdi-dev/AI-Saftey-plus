Value (String)SeverityDescription

no_vestmediumWorker not wearing a safety vest
mobile_phonemediumWorker using a mobile phone on-site

person_fallenhighPerson fall/collapse detected (emergency)

camera_blockedmediumCamera view obstructed/covered
